
UI rendering error debug guide: if the browser console shows a rendering error that references code which does NOT exist in the source file on disk (e.g. a `ReferenceError` for an import/variable that was renamed or removed, or error line numbers that do not match the file), the running vite dev server is likely serving a stale HMR/transform cache (can happen after heavy file changes, git stash/branch switches, or added/deleted files). First confirm the served module differs from disk (`curl localhost:5173/src/<path>` vs the file), then restart `npm run dev` (kills both the vite client and the API server — rerun it) and hard-reload the page before debugging the code further.
